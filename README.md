# Cruce predial y ambiental · Ciclorrutas Sabana

Página pública que cruza por abscisa el estado predial del contratista (hoja «FRENTES DE OBRA 2026») con los permisos ambientales
(archivo más reciente de la carpeta SEGUIMIENTO PERMISOS AMBIENTALES), para ver los frentes liberados y en revisión con y sin restricción ambiental.

Las dos fuentes se leen en vivo cada vez que se abre la página. Si alguna no responde, se muestra su corte guardado y se avisa arriba.
